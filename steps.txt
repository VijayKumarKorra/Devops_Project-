STEP 1 — Create the .env file

Open File Explorer → go to E:\PROJECT2\userapi\ → create a new text file named .env (exactly, no .txt extension).

Put this inside it:

DB_HOST=localhost
DB_PORT=5432
DB_NAME=userapi_db
DB_USER=postgres
DB_PASSWORD=postgres
SECRET_KEY=my-super-secret-key

▎ Note: When the app runs inside Docker Compose, DB_HOST=postgres (the service name). For local run, it's localhost. The .env is for local-only use.

---
STEP 2 — Start PostgreSQL + pgAdmin with Docker Compose

This single command starts PostgreSQL and automatically creates userapi_db + starts pgAdmin:

# Open a terminal in E:\PROJECT2
cd E:\PROJECT2
docker-compose up postgres pgadmin

Wait until you see something like:
userapi_postgres  | database system is ready to accept connections

Open pgAdmin in your browser: http://localhost:5050

---
STEP 3 — Connect pgAdmin to the database

In the browser at http://localhost:5050:

1. Login: email = admin@admin.com, password = admin
2. Right-click Servers → Register → Server
3. Fill in:
  - Name tab: UserAPI DB (any name)
  - Connection tab:
      - Host: postgres
    - Port: 5432
    - Database: userapi_db
    - Username: postgres
    - Password: postgres
4. Click Save

You'll see the userapi_db database in the left panel. Take a screenshot here.

STEP 4 — Start the full app with Docker Compose

Open a second terminal in E:\PROJECT2 and run:

docker-compose up --build

This starts all 3 services: PostgreSQL + pgAdmin + the Flask app.

Wait for:
userapi_app  | [INFO] Starting gunicorn ...
userapi_app  | Listening at: http://0.0.0.0:3000

Now open these in your browser and take screenshots:

- http://localhost:3000 → should show {"message": "UserAPI v1.0", "status": "running"}
- http://localhost:3000/health → should show {"status": "ok", "database": "healthy"}

STEP 5 — Test the API manually (create a user)

Open a third terminal and run these curl commands one by one:

# Create a user
curl -X POST http://localhost:3000/users \
  -H "Content-Type: application/json" \
  -d "{\"username\": \"alice\", \"email\": \"alice@example.com\", \"firstname\": \"Alice\", \"lastname\": \"Smith\"}"

# Get all users
curl http://localhost:3000/users

# Get user by ID (replace 1 with the id returned above)
curl http://localhost:3000/users/1

# Update a user
curl -X PUT http://localhost:3000/users/1 \
  -H "Content-Type: application/json" \
  -d "{\"firstname\": \"Alicia\"}"

# Delete a user
curl -X DELETE http://localhost:3000/users/1

Now go back to pgAdmin → expand userapi_db → Schemas → public → Tables → right-click users → View/Edit Data → All Rows. Take a screenshot of the table.

- Install Python, PostgreSQL
- Deploy and start your app
- Run a health check automatically

When done, take a screenshot of the terminal output.

vagrant halt    # stop when done

STEP 10 — Kubernetes with Minikube

Make sure Minikube is installed. Then:

minikube start

cd E:\PROJECT2
kubectl apply -f k8s/persistent-volume.yaml --validate=false
kubectl apply -f k8s/persistent-volume-claim.yaml --validate=false
kubectl apply -f k8s/deployment.yaml --validate=false
kubectl apply -f k8s/service.yaml --validate=false
Check everything is running:
kubectl get pods          # wait until STATUS = Running
kubectl get services
kubectl get pv,pvc

Take a screenshot, then open the app:
minikube service userapi-service --url

Open that URL in browser. Take a screenshot.

Cleanup:
kubectl delete -f k8s/
minikube stop
